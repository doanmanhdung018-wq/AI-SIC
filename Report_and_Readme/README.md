# 📚 THƯ MỤC TÀI LIỆU BÁO CÁO & CẨM NANG (`Report_and_Readme/`)

> **Ghi chú báo cáo Hội đồng**: Toàn bộ hệ thống tài liệu học tập, báo cáo kỹ thuật và các script tự động kết xuất sang PDF trong thư mục này được xây dựng với sự **đồng hành và hỗ trợ của AI** (AI-Assisted Documentation & PDF Generation). Thư mục này phục vụ mục đích lưu trữ mã nguồn tài liệu và đẩy lên kho lưu trữ GitHub.

---

## 1. Danh mục các tệp trong thư mục:

1. **`Report AI SIC.pdf`**: Bản PDF Báo cáo Tốt nghiệp chính thức (Trang bìa: BÁO CÁO - Đoàn Mạnh Dũng, có mục lục liên kết nhảy trang tự động).
2. **`README AI SIC.pdf`**: Bản PDF Cẩm nang Kỹ thuật toàn diện (Trang bìa: README, có mục lục liên kết nhảy trang tự động).
3. **`report.md`**: File Markdown nội dung của Báo cáo chính thức.
4. **`report.html` & `README.html`**: Các file giao diện HTML/CSS được căn chỉnh chuẩn in ấn dùng để kết xuất ra PDF.
5. **`Bao_Cao_Va_On_Tap_Thuyet_Trinh.md`**: Cẩm nang ôn thi cấp tốc: Từ điển giải ngố từ 0 đến chuyên gia, Kịch bản thuyết trình 10 phút, Bộ 25 câu hỏi phản biện điểm 10.
6. **`build_all_documents_and_pdfs.py`**: Script Python tự động sinh các file markdown, html và kết xuất sang PDF thông qua Chrome Headless với liên kết mục lục tự động.
7. **`create_full_report.py`**: Script phụ trợ biên soạn nội dung tài liệu.
